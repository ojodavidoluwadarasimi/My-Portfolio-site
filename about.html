ABOUT ME

Building intelligent systems. Learning by shipping.

I'm Ojo David Oluwadarasimi, a Software Engineering student at Obafemi Awolowo University with a clear focus: becoming a capable AI Software Engineer who also understands systems and quantitative thinking.

I build practical digital products — from full CBT learning platforms to clean personal tools — and treat every project as both a useful outcome and a deliberate learning step.

My current stack centers on HTML, CSS, JavaScript and modern web foundations. I'm actively expanding into React, TypeScript, Node.js, prompt engineering, and the broader concepts behind reliable systems and AI-assisted products.

What I'm Focused On

  • Building responsive, usable web applications that solve real problems
  • Strengthening software engineering fundamentals and system thinking
  • Exploring AI tooling, prompt engineering, and intelligent interfaces
  • Developing the quantitative mindset useful for data-driven systems
  • Shipping projects that demonstrate how I think, learn, and deliver

My Approach

Good software is more than code that runs. It should be useful, understandable, maintainable, and designed around the people who use it.

That belief shapes how I work: break problems down, build, test against reality, debug thoroughly, and improve. I prefer shipping something real over collecting unfinished tutorials.

I'm still early in the journey, but intentional about the direction — becoming an engineer who can design reliable systems and ship products that matter.

Beyond the Code

I'm drawn to the intersection of technology, clear thinking, and practical impact. Whether it's helping students prepare for exams more effectively or exploring how AI can improve everyday workflows, I want the work I do to be genuinely useful.

Every project is another chance to learn something new and become a sharper engineer.

I'm not trying to know everything. I'm building the skills to create almost anything.
